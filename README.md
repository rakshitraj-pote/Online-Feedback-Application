# Examination Center Experience
An online feedback application for students to submit feedback about their examination centre experience, and for staff to view feedback statistics.

## Student Accounts
Students can login, complete the feedback questionnaire, and then submit their feedback.
Each student can submit feedback only once.
Existing 300 Student Accounts:
- **Username:** `StudentName1` to `StudentName300`
- **Password:** `StudentPass1` to `StudentPass300`

The number at the end of the username corresponds to the number at the end of the password.
**Example:**
- Username: `StudentName1`
- Password: `StudentPass1`

## Staff Accounts
Staff can login to view the total number of feedback submissions and average ratings for each feedback category.
Existing 3 Staff Accounts:
- **Username:** `StaffName1`, `StaffName2`, `StaffName3`
- **Password:** `StaffPass1`, `StaffPass2`, `StaffPass3`

Each staff username corresponds to its matching password.
**Example:**
- Username: `StaffName1`
- Password: `StaffPass1`

## Notes
- Select the correct role on the login page: **Student** or **Staff**.
- Student accounts are only for submitting feedback.
- Staff accounts are for viewing all the feedback statistics.
- These are demonstration accounts generated for the project.
